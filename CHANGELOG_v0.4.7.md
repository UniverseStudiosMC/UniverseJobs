# 🎉 **UniverseJobs v0.4.7 - What's New!**

## ✨ **NEW FEATURES**

### 🏆 **Better Job Information**
- **Job Limit Display**: You can now see how many jobs you can have maximum in the main menu
- **Back Button**: Added a handy back button in reward menus to easily return to your job menu
- **Custom Player Heads**: Server admins can now use custom skull textures in menus

### 🎁 **Improved Rewards**
- **Better Reward Pages**: Reward menus now work properly on all pages (page 2, 3, etc.)
- **Smarter Rewards**: Rewards now show different colors and messages based on whether you can claim them or not
- **Custom Layouts**: Each reward page can have its own unique layout

---

## 🔧 **IMPROVEMENTS**

### 📋 **Menu Experience**
- **Faster Menus**: All menus load faster and work more smoothly
- **Better Navigation**: Fixed issues where some menu buttons weren't working
- **Cleaner Look**: Removed duplicate items and made menus look cleaner

### 🎯 **Job System**
- **Hunter Job**: All animals now show their correct egg icon in the action menu
- **Farmer Job**: Improved farming job configuration and rewards
- **Material Fixes**: Fixed crashes when invalid items were configured

### 📊 **Performance**
- **Faster Startup**: Plugin starts up quicker with less spam in console
- **Less Lag**: Reduced memory usage and improved overall performance
- **Cleaner Shutdown**: Plugin shuts down more cleanly without spam messages

---

## 🐛 **BUG FIXES**

### 🔨 **Major Fixes**
- **Reward Menu Crashes**: Fixed crashes when reward menus had invalid items
- **Page 2+ Not Working**: Fixed reward menus where you couldn't click anything on page 2 and beyond
- **Menu Items Missing**: Fixed missing background items in menus when starting the server
- **Job Limit Not Showing**: Fixed the job limit not displaying in the main menu

### 🔧 **Minor Fixes**
- **Item Grouping**: Fixed items not grouping properly in action menus
- **Menu Refreshing**: Fixed menus not updating properly after changes
- **Default Settings**: Fixed menu items using wrong default configurations

---

### 👤 **For Regular Players:**
- **Better Experience**: Menus work smoother and look better
- **More Information**: You can see more useful info about your jobs and limits

### 👑 **For Server Admins:**

## 📦 **Installation**

1. **Stop your server**
2. **Replace the old UniverseJobs.jar** with the new one
3. **Start your server** - everything will update automatically!

> **Note**: Your existing configurations will work fine, but you might want to check out the new features!
